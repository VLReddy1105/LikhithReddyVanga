## Idea A — "Neural Monochrome" (Dark Bauhaus × AI Research)

**Design Movement:** Dark Bauhaus meets computational aesthetics

**Core Principles:**
- Pure black background with off-white text — maximum contrast, zero noise
- Typography as the primary visual element — size hierarchy tells the story
- Sparse layout with intentional empty space — every element earns its place
- Thin rule lines as dividers — geometric precision

**Color Philosophy:**
- Background: #0A0A0A (near-black, not pure black)
- Foreground: #F0EDE8 (warm off-white)
- Accent: #C8FF00 (electric lime — the "AI spark")
- Secondary accent: #4A4A4A (dark grey for muted text)
- Emotional intent: Authority, precision, intellectual depth

**Layout Paradigm:**
- Asymmetric two-column hero: name/title left-anchored, tagline right
- Horizontal scrolling timeline for experience
- Bento-grid for projects with varying card sizes
- Full-bleed section separators

**Signature Elements:**
- Animated dot-grid background (very subtle, low opacity)
- Lime green underline on hover states
- Monospace font for code/tech terms

**Interaction Philosophy:**
- Cursor dot that follows mouse
- Section transitions: fade + slight vertical shift
- Hover: text color inversion on CTAs

**Animation:**
- Loading: typewriter effect for name
- Scroll: staggered fade-in per section
- Cards: subtle lift on hover (translateY -4px)

**Typography System:**
- Display: "Space Grotesk" Bold 700 — for name, section headers
- Body: "DM Sans" Regular 400 — for descriptions
- Code: "JetBrains Mono" — for tech stack tags

## Idea B — "Warm Ivory Research Lab" (Editorial × Academic)

**Design Movement:** Editorial minimalism meets academic journal aesthetics

**Core Principles:**
- Warm ivory/cream background — approachable, human, scholarly
- Serif display + sans-serif body — classic academic tension
- Left-aligned everything — reading flow, not centering
- Generous vertical rhythm — breathing room between ideas

**Color Philosophy:**
- Background: #FAF7F2 (warm ivory)
- Foreground: #1A1A1A (near-black)
- Accent: #2563EB (electric blue — academic precision)
- Secondary: #E8E2D9 (warm grey for cards)
- Tertiary: #DC2626 (red for highlights/tags)
- Emotional intent: Intelligence, warmth, credibility

**Layout Paradigm:**
- Single-column editorial layout with wide margins
- Pull-quotes and callouts in margins
- Timeline as vertical list with year markers
- Project cards as editorial feature blocks

**Signature Elements:**
- Large serif numerals for section numbering (01, 02, 03...)
- Thin horizontal rules between sections
- Red dot bullet points for key achievements

**Interaction Philosophy:**
- Smooth scroll with section highlighting in nav
- Cards expand on hover to show more detail
- Links have underline-draw animation

**Animation:**
- Loading: horizontal progress bar + fade in
- Scroll: elements slide in from left
- Nav: active section indicator slides

**Typography System:**
- Display: "Playfair Display" Bold — for name, hero headline
- Section headers: "Space Grotesk" SemiBold
- Body: "Inter" Regular — for readability
- Tags: "JetBrains Mono" — for tech stack

## Idea C — "Obsidian Terminal" (Dark Glassmorphism × Sci-Fi Minimal)

**Design Movement:** Dark glassmorphism meets terminal/CLI aesthetics

**Core Principles:**
- Deep navy/slate dark background with glass card surfaces
- Monospace accents for tech credibility
- Gradient glows for depth — not flat, but not loud
- Grid-based layout with intentional asymmetry

**Color Philosophy:**
- Background: #0D1117 (GitHub dark — deep navy-black)
- Surface: rgba(255,255,255,0.05) (glass cards)
- Accent: #58A6FF (GitHub blue — familiar to devs)
- Secondary accent: #3FB950 (terminal green)
- Muted: #8B949E (grey for secondary text)
- Emotional intent: Technical mastery, modern, developer-native

**Layout Paradigm:**
- Full-viewport hero with animated particle/neural network background
- Sticky sidebar navigation on desktop
- Masonry grid for projects
- Terminal-style skill display

**Signature Elements:**
- Glowing border on active nav items
- Blinking cursor on hero tagline
- Code-block styled skill tags

**Interaction Philosophy:**
- Parallax depth on hero section
- Cards with glass blur on hover
- Terminal typing animation for intro text

**Animation:**
- Loading: terminal boot sequence animation
- Scroll: reveal animations with spring physics
- Background: subtle floating particles

**Typography System:**
- Display: "Syne" ExtraBold — for name (geometric, futuristic)
- Body: "Inter" Regular — clean readability
- Code: "Fira Code" — for tech tags and terminal elements
